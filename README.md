# IA para estudiantes de Formación Profesional

Guía interactiva desde cero para estudiantes de FP: qué es la IA, para qué sirve de verdad y por qué pensar por ti mismo sigue siendo lo importante.

> **EN** · Beginner-friendly interactive guide to AI for vocational students, focused on critical thinking.

🔗 **Demo:** [inteligenciaartificialestudiantes.sanidadedtech.es](https://inteligenciaartificialestudiantes.sanidadedtech.es/)

## Para quién es

Alumnado de Formación Profesional de cualquier familia.

## Qué incluye

- Qué es la IA y por qué a veces falla
- Qué puedes hacer con ella, con ejemplos por sector
- Cómo pedirle las cosas bien
- Pensamiento crítico y autoría propia

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Barra de progreso con forma de electrocardiograma
- Índice interactivo que sigue la lectura
- Un solo archivo, sin dependencias
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
