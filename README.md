# IA para estudiantes de Formación Profesional 🩺🤖

Guía interactiva web diseñada para acompañar a estudiantes de Formación Profesional (FP) en el uso práctico, ético y crítico de la inteligencia artificial generativa, sin dependencias externas y lista para abrir en cualquier navegador.

---

## 📌 Sobre el proyecto

Este proyecto consiste en un recurso educativo en formato **single-file HTML** desarrollado por **V. López (@sanidadedtech)**. Parte desde cero, sin dar conocimientos técnicos por sabidos, y aborda cómo integrar herramientas como ChatGPT, Claude o Gemini como asistentes de estudio y trabajo práctico sin perder el pensamiento crítico ni la autoría propia.

### ✨ Características principales
- **Autocontenido (*Single File*):** Todo el código (HTML5, CSS3, JavaScript y recursos) se encuentra en un único archivo sin dependencias de frameworks ni scripts externos.
- **Interactividad nativa:**
  - 📈 *Barra de progreso estilo electrocardiograma (Pulse progress bar)* sincronizada con el scroll.
  - 🧭 *Tabla de contenidos (TOC) interactiva* con efecto *Scrollspy*.
  - 📑 *Pestañas por familias profesionales:* Ejemplos concretos adaptados a Informática, Administración, Sanidad, Hostelería, Automoción e Imagen Personal.
  - 📂 *Acordeones dinámicos* con retos prácticos semanales[cite: 1].
  - 📝 *Cuestionario de autoevaluación interactivo* con retroalimentación inmediata, puntuación y reinicio[cite: 1].
  - ✅ *Lista de chequeo mental* antes de entregar tareas[cite: 1].
- **Diseño *responsive* y accesible:** Adaptado a pantallas móviles y de escritorio, con soporte para `prefers-reduced-motion`[cite: 1].
